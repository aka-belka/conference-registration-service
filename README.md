# Сервис регистрации участников конференции
  
## Назначение 
  
Сервис помогает автоматизировать процесс регистрации участников на конференцию. Оно позволяет организаторам управлять мероприятиями, отслеживать статус участников и выдавать билеты. 
  
## Целевая аудитория 
  
Организаторы конференций и мероприятий. Участники, желающие зарегистрироваться на конференцию. Администраторы, управляющие списками участников.
  
## Предметная область 
  
Управление регистрацией на конференции. В системе выделяются мероприятия, участники, билеты и статусы регистрации. Каждое мероприятие имеет определённое количество мест, дату проведения и список зарегистрированных участников. Участник может зарегистрироваться на одно или несколько мероприятий, получить билет с уникальным номером и статусом. 
  
## Основные сущности 

- Участник
- Мероприятие
- Билет
- Статус
  
## Основные функции 

- Регистрация нового участника
- Создание мероприятия с указанием даты и максимального числа мест
- Бронирование билета на мероприятие
- Изменение статуса билета
- Просмотр списка участников мероприятия
